Face Mask Detection System Using Django
Project Description
This project is a web application developed using the Django framework that detects whether a person is wearing a face mask or not from an uploaded image. The system uses image processing and machine learning techniques to identify faces and classify them as Mask or No Mask.
Technologies Used

Frontend: HTML, CSS, JavaScript


Backend: Django (Python)


Database: SQLite


Programming Language: Python


Machine Learning: Face Detection and Mask Classification Model


Tools: VS Code, Git, GitHub


Modules


Open Web Application


User accesses the website through a browser.




Upload Image


User uploads an image containing one or more faces.




Image Storage


The uploaded image is stored on the server.




Face Detection


The system detects faces present in the image.




Mask Classification


Each detected face is classified as:


Mask


No Mask






Result Visualization


Bounding boxes and labels are displayed on the image.




Result Summary


Shows the total number of faces detected and mask status.




Workflow
User → Upload Image → Face Detection → Mask Classification → Display Results → Generate Summary
Advantages


Easy to use through a web browser.


Fast and accurate mask detection.


Can monitor safety compliance in public places.


Centralized data management through Django.
